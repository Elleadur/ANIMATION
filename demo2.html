Keyboard shortcuts

    

      
SpacePlay / Stop

      
1-8Recall scene (on next bar). Shift+1-8 saves a scene

      
MMutate (one-shot variation)

      
RRegenerate all unlocked tracks

      
TCycle theme

      
↑ ↓BPM +1 / -1 (Shift = 5)

      
← →Energy -5 / +5

      
B D FBuild-up / Drop / Fill (when piano mode is off)

      
KToggle computer-keyboard piano mode

      
Piano modeZ S X D C V G B H N J M / Q 2 W 3 E R 5 T 6 Y 7 U I play notes, - = octave

      
?Show / hide this help

      
EscClose help, leave piano mode

      
Ctrl+Z / Ctrl+YUndo / redo timeline actions

      
Timeline focusedArrows move clips (or the playhead), Shift+arrows resize, Enter clip settings, Delete,
        Ctrl+D duplicate, S split, J merge, G generate, , . select clips,
        L loop, [ ] loop points, E energy point, 1-8 scene marker

      
Lane header focusedAlt+↑/↓ moves the lane

      
Timeline mouseCtrl+wheel zoom, Ctrl+Shift+wheel lane height, Shift+wheel scroll

      
Grid focusedArrow keys move the cursor, Enter toggles a step

    

    
Shortcuts are ignored while you type in a text or number box.
